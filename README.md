# Pemba Town Council Data Mining Project
**CSC 4792 Data Mining & Warehousing | Team #42 | Sept 2026**

## 📋 Project Overview
Extraction, cleaning, and curation of Pemba Town Council's public datasets for transparency and governance research.

### Key Data Domains
- **CDF Allocations**: Constituency Development Fund project tracking
- **Budget Analysis**: LGEF, locally generated revenue, financial allocations
- **Strategic Projects**: Infrastructure, health, water & sanitation initiatives
- **Council Governance**: Resolutions, ward committee data, administrative records
